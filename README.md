## 🛠️ Repository & System Structure

- **`src/`**: Contains compiled, tested Java source files grouped by day.
- **`scripts/`**: Houses the templates database and `PracticeBot.java` which automates streaks cleanly.

## 🧑‍💻 Running Solutions Locally

Each Java file is structured to be standalone and runnable without dependencies. You can run any file directly using standard JDK:
```bash
java src/day01/Easy_TwoSum.java
```
The program automatically runs self-contained assertion checks and prints confirmation on success.
